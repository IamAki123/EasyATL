# Security Policy

EasyATL is an FTC localization library. If you find a vulnerability that could affect robots, teams, or published artifacts (for example a dependency issue in a release), please **do not** open a public GitHub issue.

Email **Akash Vijay Aradhya** via the contact on [github.com/IamAki123](https://github.com/IamAki123) and include the EasyATL version and a description of the issue.

For incorrect poses, filtering bugs, or build problems, use a [bug report](https://github.com/IamAki123/EasyATL/issues/new?template=bug_report.md) instead.
